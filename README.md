Описание

ЖК Актив — это веб-приложение для управления многоквартирным домом. Оно объединяет прозрачные финансы, голосования жильцов, учёт задолженностей, заявки на бытовые услуги, обсуждения и общий чат. Всё работает прямо в браузере, данные хранятся в localStorage, сервер не нужен.
Возможности
Для всех жильцов:
Панель управления с ключевыми показателями: баланс фонда, доходы и расходы за месяц, общий долг, количество активных заявок.
Графики по месяцам: доходы, расходы, баланс, а также задолженность по квартирам.

Голосования: участие в опросах с мгновенным подсчётом результатов, один голос на пользователя.
Финансы: просмотр истории операций фонда дома.
Долги: личная задолженность с детализацией по назначениям.
Обсуждения: создание тем и комментирование.
Услуги: заказ бытовых услуг (уборка, сантехник, электрик и другие) с оплатой из фонда.
Чат дома: общий чат жильцов.
Личный кабинет: профиль, долг, список собственных заявок.

Для администратора:
Подтверждение и отклонение регистраций новых жильцов.
Создание и удаление голосований.
Добавление доходов и расходов в фонд дома.
Начисление долгов жильцам и отметка об оплате, при которой автоматически создаётся доходная операция.
Добавление и удаление услуг.
Управление заявками: перевод в работу, отметка о выполнении, отмена.
Добавление жильцов вручную и удаление аккаунтов.
Удаление тем обсуждений.

Технологии
HTML5 для разметки.
CSS3 с кастомными свойствами, Grid, Flexbox и анимациями.
Чистый JavaScript (ES6+, модуль в виде IIFE).
Chart.js 4.4 для графиков.
Font Awesome 6 для иконок.
Google Fonts, шрифт Inter.
localStorage для хранения данных.

Внешние зависимости подключаются через CDN. Сборка и npm не требуются.

Быстрый старт
Скачайте файл ЖК АКТИВ.html.
Откройте его в любом современном браузере: Chrome, Firefox, Edge или Safari.
Войдите под демо-аккаунтом или зарегистрируйте нового жильца.
Для корректной работы CDN-ресурсов (шрифты, иконки, Chart.js) нужно подключение к интернету.

Логика работы

Аутентификация:
Логин ищется без учёта регистра, приводится к нижнему регистру.
Новый пользователь после регистрации получает статус «не подтверждён» и не может войти, пока администратор не подтвердит заявку.
Пароли хранятся в открытом виде в localStorage, это демо-проект, не используйте его в продакшене.

Финансы:
Баланс равен сумме доходов минус сумма расходов.
Расход не может превысить текущий баланс, проверка выполняется при добавлении операции и заказе услуги.
При отметке долга оплаченным автоматически создаётся доходная операция на сумму долга.

Голосования:
У каждого пользователя один голос на опрос.
Результаты пересчитываются в процентах от общего числа голосов.

Заявки на услуги:
При заказе средства списываются из фонда как расход и создаётся заявка со статусом «Новая».
Статусы: «Новая», «В работе», «Выполнена», «Отменена».
Заявки можно фильтровать по статусу.
Требования к паролю
Пароль должен содержать:
минимум 6 символов;
минимум одну заглавную букву (A–Z);
минимум один спецсимвол из набора !@#$%^&*.
Проверка выполняется как при регистрации, так и при создании жильца администратором.

Хранение данных
Все данные сохраняются в localStorage под ключами:
hk_u — пользователи.
hk_p — голосования.
hk_d — обсуждения.
hk_t — финансовые операции.
hk_s — услуги.
hk_o — заявки.
hk_c — сообщения чата.
hk_db — задолженности.

При первом запуске, когда localStorage пуст, автоматически загружаются демо-данные. Данные привязаны к конкретному браузеру и файлу, очистка кэша браузера удалит всё.
Сброс демо-данных
В разделе «Финансы» есть кнопка «Сбросить демо». Она очищает localStorage и перезагружает страницу, возвращая исходный набор демо-данных. Альтернативно можно очистить данные сайта в настройках браузера.
Ограничения и планы развития

Текущие ограничения:
Нет бэкенда, данные локальны для каждого браузера, синхронизации между устройствами нет.
Пароли хранятся в открытом виде.
Нет восстановления и смены пароля.
Нет пагинации, при большом объёме данных списки могут замедляться.
Возможные направления развития:
Перенос на серверную часть (Node.js/Express + PostgreSQL) с JWT-аутентификацией.
Хеширование паролей (bcrypt или argon2).
WebSocket для чата и уведомлений в реальном времени.
Push-уведомления о новых голосованиях и заявках.
Экспорт финансовых отчётов в PDF или Excel.
Мобильное приложение или PWA.
Интеграция с платёжными системами для оплаты долгов.
